# Personal photoreal Telegram bot

Jork-style: **send up to 10 photos → tap a preset → every photo is converted**.

Day to day you only use Telegram. A GPU on [RunPod](https://www.runpod.io) wakes when you send photos and sleeps after. The bot itself stays online on [Railway](https://railway.app).

**Owner: read [YOUR_STEPS.md](YOUR_STEPS.md).** That is the whole one-time setup.

- Model: [Z-Image-Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo)
- Adults only (blocks underage *prompts*; no “looks 18” visual filter)
- This folder is independent of StockPulse
